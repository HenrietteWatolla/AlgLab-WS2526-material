One seperate performance profile for each of the instance classes:
- trivial instances
- regular graphs
- dense graphs
- erdos renyi graphs
- barabasi albert graphs
- kneser graphs
- dimacs instances


Observations

- For trivial graphs the best solution k = number of nodes is already given through the heuristics and every heuristic delivers same value (performance profile remains empty).

- In almost all graph classes dsatur outperforms greedy completely. Dsatur finds even for all instances the best heuristic solution considering barabasi albert graphs, dense, regular and erdos renyi graphs.
However, kneser instances are an exception where greedy is able to find the best heuristic solution. This is interesting, because kneser graphs are also regular. Therefore, they need to have additional characteristics (in comparison to the other considered regular graphs) that lead to the effectiveness of greedy.

Overview
